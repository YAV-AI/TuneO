# Getting help with TuneO

- **How do I...?** Start with the in-app **Help** page (sidebar, More, Help) and the [README](README.md), especially Quick start, Configuration and Troubleshooting.
- **Found a bug?** Open an issue using the **Bug report** form. Include steps to reproduce and logs, with keys removed.
- **Have an idea?** Open an issue using the **Feature request** form.
- **KIE account, credits or model access?** Those are handled by [KIE AI](https://kie.ai), not this project.
- **Security problem?** Report it privately as described in [SECURITY.md](SECURITY.md).

TuneO is maintained in spare time, so please be patient. Clear, reproducible reports get fixed fastest.
